# Campfire

A single-page P2P cozy hangout. Open the link, you're a little SDF blend-shell
creature standing around a firepit at dusk. No install, no server, no room
codes: peer-to-peer over Trystero/WebRTC, the link is the room.

Live at https://tront.xyz/campfire/

Dev source: https://github.com/TrentSterling/campfire-dev (private)
